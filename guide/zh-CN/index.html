epher 用户指南

欢迎！epher 是一款可编程、可脚本化的计算器。你可以用它做快速计算，也可以构建自己的函数和小程序。所有功能都支持八种语言。

本指南面向完全初学者。它从最简单的计算开始，逐步深入到语言的完整功能。每个示例都显示你输入的内容以及 epher 的回应。

epher 有五种使用方式。选择最适合你的那一种：

版本 是什么 何时选用
命令行（CLI） 终端中的文本命令 常驻终端、喜欢脚本
REPL epher> 提示符下的交互式 epher 会话 想要快速往返，无需离开终端
终端界面（TUI） 终端内的全屏程序 想要带图表和屏幕历史的终端应用
桌面应用 带独立窗口的常规桌面程序 想要一个常规应用程序
网页应用（PWA） 在浏览器中运行，可安装，可离线使用 想最快开始；无需安装

桌面应用、命令行、REPL 和终端界面是同一个程序：一次下载安装的 epher 命令能完成这四件事。网页应用是例外：完全无需下载。

五个版本理解完全相同的语言。学会一次，随处可用。

1. epher 语言

本章讲解所有 epher 版本共享的语言。在网页应用或桌面应用中，输入表达式并按回车（或点击 = 按钮）。在 CLI 中，用 epher repl 启动会话，然后在 epher> 提示符后输入。在 TUI 中（epher tui），直接输入并按回车。在 CLI 中你也可以输入 epher "表达式" 直接计算一个表达式。

1.1 你的第一个计算

输入：

2 + 3 * 4

epher 回答：

14

乘法和数学中一样先于加法计算。这个规则称为运算符优先级。

1.2 运算顺序

完整的优先级顺序，从强到弱：

  1. ! 阶乘和 % 百分比（均为后缀）
  2. ^ 乘方
  3. * 和 / 乘法和除法
  4. + 和 - 加法和减法

用括号改变顺序：

(2 + 3) * 4
20

^ 运算符计算乘方，并且从右向左结合：

2 ^ 10
1024

2 ^ 3 ^ 2
512

（2 ^ 3 ^ 2 表示 2 ^ (3 ^ 2)，即 2 ^ 9 = 512。）

乘方可以是分数。2 ^ 0.5 就是 2 的平方根：

2 ^ 0.5
1.41421356237

减法和除法从左向右计算：

10 - 3 - 2
5

% 符号是一个后缀运算符，意思是“除以 100”：5% 即 0.05。它从不看周围的运算符，所以 200 + 10% 是 200.1。要把 200 增加 10%，请写出乘法：

200 * (1 + 10%)
220

1.5 变量

用一个 = 给值命名：

x = 5
5

epher 会把值重复给你。从现在起，x 可以随处使用：

x ^ 2
25

你可以随时更改变量。它一直保持自己的值，直到你更改它：

x = x + 1
6

名称可以包含字母和下划线，如 radius 或 my_total。不能包含空格，也不能以数字开头。

有一个名字是保留的：i，虚数单位（见 1.18 节）。

特殊变量 ans 始终保存上一个答案，就像口袋计算器的 Ans 键， 适合连续计算：

2 + 3
ans * 2
5
10

一个列表可以一次填入多个名字：{a, b} = list 把列表从左到右拆开 （1.11 节会展示这样返回多个答案的函数）：

{a, b} = {10, 20}; a + b
{10, 20}
30

不想要的位置写作 _：

{x, _} = {7, 8}; x
{7, 8}
7

1.6 常量：永不改变的名称

常量是一个值永不改变的名称，就像内置的 pi，但由你自己选择。用 const 定义：

const tax = 0.2
0.2

在任何可以使用数字的地方都可以使用它：

100 * (1 + tax)
120

这个值是固定的：用 = 修改它会报错，

tax = 0.25
error: cannot assign to constant tax

用不同的值重新定义同一个常量同样会报错：

const tax = 0.25
error: constant already defined: tax

常量与变量还有一个不同之处：和 pi 一样，它可以在你自己的函数里使用。

const g = 9.81
9.81

def weight(m) = m * g
weight(80)
784.8

像保存函数一样，用 save tax 把常量保存到以后的会话（第 4.4 章）。

变量和常量不能共用一个名称：const tax = 0.2 之后，tax = ... 永远是 错误。换一个新名称，或开始一个新的会话。

1.8 用 if 做判断

if 在两个值之间选择：

if 3 > 2 then 10 else 20
10

形式永远是 if 条件 then 为真时的值 else 为假时的值。else 部分必不可少。

带变量的更有用示例：

price = 100
if price > 50 then 2 else 1
100
2

if 现在也能比较字符串（见 1.7 节）：两支只要求同类的值： 数字对数字，字符串对字符串。

1.9 用 while 循环

只要条件成立，while 就重复执行一条语句：

x = 0; while x < 5 do x = x + 1; x
0
5

把这个脚本读作：*x 从 0 开始；当 x 小于 5 时，给 x 加 1；然后显示 x。*结果是 5，因为循环执行了五次。

安全网： epher 会在 100 000 步之后停止任何循环并显示 error: step limit exceeded。这能保护你免受永不结束的循环的困扰。如果看到这个错误，说明你的条件可能永远不会变成假。

循环也可以主动离开：下一节加入 break 和 continue，函数则有 return（见 1.11 节）。

1.10 用 for 循环

for 对每个值重复一次语句，并把语句的值收集成一个列表：可以遍历 start to end 区间（含端点，可带 step），也可以遍历列表的元素：

for i in 1 to 5 do i^2
for x in {2, 3, 4} do 10*x
for i in 0 to 1 step 0.5 do i
{1, 4, 9, 16, 25}
{20, 30, 40}
{0, 0.5, 1}

循环变量的作用域仅限于循环：结束后该名恢复之前的含义（对 i 的循环不会影响虚数单位），而循环体内对其他名字的赋值仍然保留。配合 print，循环能写出可读的行：

for i in 1 to 3 do print("line", i)
{line 1, line 2, line 3}

与 while 一样，10 万步的安全网同样限制 for 循环。

提前离开循环。 break 就地停止循环；到此为止收集到的值就是循环 的答案。continue 跳过本轮剩余部分，进入下一个值。两者都是语句， 所以放在 if 后面：

for k in 1 to 6 do if mod(k, 2) == 1 then k
for k in 1 to 10 do if k == 4 then break else k
total = 0
for k in 1 to 6 do if mod(k, 2) == 0 then continue else total = total + k
total
{1, 3, 5}
{1, 2, 3}
0
{1, 4, 9}
9

中间那个读作：k 从 1 到 10，如果 k 是 4 就停止；否则交回 k。循环的 答案是它停止之前看到的值。最后一对展示 continue 计数：for 行收集 的列表是累计和 - 1，然后 4，然后 9 - 偶数轮被跳过，所以什么也没加。 最后的 total，9，是奇数值的和。没有 else 的 if 在条件为假时 什么也不贡献，第一个循环正是这样只留下奇数值，循环也正是这样既能 筛选一个列表，也能变换它。

1.11 用 def 定义自己的函数

函数是带有名称和参数的计算：

def f(x) = x ^ 2

然后使用它：

f(7)
49

函数可以有多个参数：

def area(w, h) = w * h
area(3, 4)
12

也可以定义没有参数的函数：

def answer() = 42
answer()
42

多步的函数体。 当一个表达式不够用时，给函数一个 do … end 函数 体。语句按顺序逐条执行，最后一条的值就是答案：

def hyp(a, b) do
  c = a ^ 2 + b ^ 2
  sqrt(c)
end
hyp(3, 4)
5

中间名字 c 存在于调用内部；外部看不见它，两次调用也看不见彼此的 c。

return：立刻给出答案。 return value 立即作答并跳过函数体的其 余部分：带提前出口的选择，这是最自然的形状：

def grade(s) do
  if s >= 90 then return "A"
  if s >= 80 then return "B"
  "C"
end
grade(95); grade(85); grade(40)
A
B
C

return 也会在搜索的循环找到的那一刻离开循环：

def firstsq(xs) do
  for x in xs do
    if x ^ 0.5 == floor(x ^ 0.5) then return x
  0
end
firstsq({3, 5, 9, 11}); firstsq({3, 5, 7})
9
0

一条规则让这些块保持可读：end 永远闭合函数的 do：if、for、 while 都不带 end。函数体在没有答案的情况下结束（比如每条路径都 没返回任何东西）是一个错误，而不是沉默：epher 会说明这一点，并点名 那个函数。

不止一个答案？ 返回一个列表：并用 1.5 节的解构一举命名： {mean, sd} = {4, 1.6}。

1.12 递归：调用自身的函数

最著名的例子是斐波那契数列：

def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
fib(10)
55

fib(10) 是第 10 个斐波那契数。函数用更小的参数调用自己，直到达到 n <= 1。这能成立是因为 if ... then ... else ... 形式只计算它需要的分支。

函数体是 = 之后的一个表达式，或是一个带多条语句的 do … end 块， 需要提前退出时用 return（见 1.11 节）。不需要函数时，改用脚本 （见下一节）组合多个计算。

1.13 脚本：一次执行多条语句

脚本是用 ; 连接或者用换行符连接，两者含义完全相同，依次执行的若干语句：

x = 10; y = x + 5; x + y
10
15
25

脚本是构建小程序的方式：设置变量、循环、显示最终结果。

换行符和 ; 是同一个分隔符，可以自由混用。多行示例上方的 复制 按钮会复制整个脚本，你可以直接把它粘贴到 epher 中：网页应用和桌面应用的输入框、终端界面，以及 epher repl 都会按顺序逐行执行，就像你逐行输入一样。用 ; 在一行中连接多条语句在任何地方同样有效，包括单次计算命令行（第 4.1 节）。

脚本可以带注释：写给你自己、由 epher 跳过的笔记，写法与 PHP 相同。// 或 # 注释到行尾，/* ... */ 注释一个块。关于某条语句的注释放在这条语句的末尾、// 之后，绝不放在语句中间：

// a small script with notes
r = 3 # radius in metres
area = pi * r ^ 2 // pi r squared
area

A block comment may also span several lines. A script file or a pasted program arrives as one whole program, so its block comments may span lines:

/* the area of a circle
of radius 3 */
pi * 3 ^ 2

Input that arrives line by line - typing into the REPL or the terminal UI, or a piped script - takes one line at a time, so there a block comment opens and closes on the same line.

1.14 精确结果：frac、dec 和 big

通常 epher 像袖珍计算器一样用小数计算，结果像袖珍计算器那样 四舍五入到十二位有效数字：0.1 + 0.2 是 0.3，绝不会是 0.30000000000000004。精确分数默认开启：能还原为小分母分数且 小数部分循环的结果会以分数显示。1 / 3 无需询问就显示为 1/3：

1 / 3
1/3

在结果设置（第 2.2 章）中关闭精确分数后，同样的除法显示 0.333333333333。frac(n, d) 生成精确分数，并在计算过程中保持 精确：

frac(1, 3)
1/3

分数在计算过程中保持精确：

frac(1, 3) * 3
1

dec(x) 生成精确小数。0.1 + 0.2 两种设置下都显示 0.3：差别 在于运算本身：

0.1 * 3 - 0.3
dec(0.1) * 3 - dec(0.3)
0.0000000000000000555111512313
0.0

浮点结果带有每台计算机处理小数时都会产生的微小舍入误差；dec() 让运算保持精确。

big(x) 生成精确整数，用于超出袖珍计算器范围的数值：

big(10 ^ 20)
100000000000000000000

数制按数学界的写法书写整数：0b 表示二进制，0o 表示八进制，0x 表示十六进制（前缀只改变拼写，从不改变值）：

0b1010 + 0xFF
265

用 bin(x)、oct(x) 和 hex(x) 转回去。它们给出一个整数的带前缀拼写， 可以直接再次使用：

hex(255)
bin(10)
0xff

0b1010

```epher

1.19 解方程

solve 求一元方程的根。方程使用 ==：

solve x^2 == 5*x + 6
x = -1, x = 6

多项式方程（由 + - * ^ 和常量构成）给出全部根，包括实根和复根：

solve x^2 == -1
solve x^2 + 2*x + 5 == 0
solve (x - 1)^2 == 0
x = -i, x = i
x = -1-2i, x = -1+2i
x = 1

要求解的变量是 x（当它出现时），否则是唯一的另一个变量。常量和已绑定的变量作为参数：

const k = 3
solve k*x == 12
3
x = 4

任何其他方程都会在 -100..100 上做数值扫描：通过符号变化括出根，所以 solve sin(x) == 0.5 会列出该范围内的每一个根。两个坦诚的限制：函数只触及零点的根（如数值路径下的 x^2 == 0）可能被漏掉，含多个未绑定变量的方程会报错。

1.20 微积分：导数与积分

derivative(expr, p) 是 expr 在 p 处的数值导数。第一个参数保持为表达式，其自由变量就是被求导的变量：

derivative(x^2, 3)
derivative(sin(t), 0)
6
1

因为参数保持为表达式，导数可以绘图：graph derivative(x^3 - x, x) 绘制斜率曲线。

integral(expr, a, b) 是从 a 到 b 的定积分，用自适应辛普森求积计算：

integral(x^2, 0, 3)
integral(sin(x), 0, pi)
9
2

integral(x^2, 3, 0) 是 -9（带符号的积分），可绘制的上限同样有效：graph integral(x^2, 0, x)。

两者都是数值计算；表达式在区间内必须取实数值，含多个变量的表达式会报错。

1.21 数据：列表、统计与回归

列表是大括号中的一列数字：{1, 2, 3}。元素是表达式，允许空列表 {}，列表可以像任何值一样绑定到名称：

d = {12, 15, 14, 16, 13, 15, 14, 17}
d[2]
len(d)

list[i] 是第 i 个元素，从 1 开始计数，与计算器一致；索引越界是 错误。方括号比 ^ 绑定更紧，所以 d[2]^2 是 (d[2])^2。

对列表的运算是逐元素进行的，单个数字会广播到每个元素：

{1, 2, 3} * 2
{1, 2, 3} + 10

两个列表做 + - * / ^ 运算时长度必须相同。== 和 != 比较整个 列表；排序比较不接受列表。

统计函数接受一个列表作为唯一参数（多参数形式保留：mean(1, 2, 3) 仍然可用）：sum product mean median mode variance stdev min max range。新的形态函数有 len(列表)、sort(列表)（升序副本）、 mode(列表)（出现最多的值，并列时取最小）、range(列表)（最大 减最小）和 quartile(列表, k)（k 为 1..3，TI 式四分位，取两半的 中位数）：

mean(d)
median(d)
quartile(d, 1)

linreg(xs, ys) 对两个等长列表拟合最小二乘直线，并连同相关系数 r 一起报告：

linreg({1, 2, 3, 4}, {2.1, 4.2, 5.8, 8.1})

拟合直线是一种显示结果，就像 solve 的根；拟合的图形在散点图上 （第 1.23 节）。

回归家族的其余部分拟合计算器长大后用到的模型：quadreg 拟合 y = a*x^2 + b*x + c（至少 3 个点），expreg 拟合 y = a*e^(b*x)（y > 0），powreg 拟合 y = a*x^b（x、y > 0），logreg 拟合 y = a + b*ln(x)（x > 0）。每个都连同 r 报出模型：

quadreg({1, 2, 3, 4}, {1, 4.1, 8.9, 16.2})
expreg({1, 2, 3}, {2.7, 7.4, 20.1})
y = 1.05*x^2 + -0.21*x + 0.2 (r = 0.9999)
y = 0.9911*e^(1.0037*x) (r = 1)

变换拟合的 r 是线性化后数据对的相关系数，与 TI 和 NumWorks 报出的数字相同。每个模型也能在散点图上自绘：graph scatter(xs, ys, quadreg)（或 expreg、powreg、logreg）会连同该模型的曲线一起画出各点。

1.22 分布与假设检验

概率函数覆盖标准正态、t、卡方、二项和泊松分布族。正态族接受一个 或三个参数：一个参数即标准正态：

normcdf(1.96)
invnorm(0.975)
normcdf(12, 10, 2)

normpdf(x[, mu, sigma])、normcdf(x[, mu, sigma])、invnorm(p[, mu, sigma])；tpdf(x, df)、tcdf(x, df)、invt(p, df)； chi2pdf(x, df)、chi2cdf(x, df)、invchi2(p, df)； binompdf(k, n, p)、binomcdf(k, n, p)；poissonpdf(k, lambda)、 poissoncdf(k, lambda)。inv* 函数回答相反的问题：invt(0.975, 10) 是下方有 97.5% 质量的 t 值。

检验函数接受一个数据列表，以显示文本报告统计量和双侧 p 值；区间 函数在您指定的水平上报告 (下, 上)：

d = {12, 15, 14, 16, 13, 15, 14, 17}
ttest(d, 14)
tinterval(d, 0.95)
ztest(d, 14, 1.5)
chisq_gof({20, 30, 25, 25}, {25, 25, 25, 25})
{12, 15, 14, 16, 13, 15, 14, 17}
t = 0.8819, p = 0.4071
(13.1594, 15.8406)
z = 0.9428, p = 0.3458
chi2 = 2, p = 0.5724

ttest(数据, mu0) 和 tinterval(数据, 水平) 使用样本标准差 (n−1)；ztest(数据, mu0, sigma) 和 zinterval(数据, sigma, 水平) 需要已知的 sigma。chisq_gof(观测值, 期望值) 是自由度为 k−1 的拟 合优度检验。结果是显示文本：可读、可复制，但算术不能使用它们。

还有两个同形的检验。anova(列表1, 列表2, …) 是对两组或更多组的单因素方差分析（长度不等也可以），连同 p 值报出 F：

anova({1, 2, 3}, {4, 5, 6}, {7, 8, 9})
F = 27, p = 0.001

ttestpaired(a, b) 是配对 t 检验：取两条等长列表的差，对 0 做检验，课堂上的"前后"对比：

ttestpaired({80, 85, 90}, {82, 84, 91})
t = -0.7559, p = 0.5286

绘图家族也接受列表：散点图、直方图和箱线图。数据图独占面板，就像 太阳系一样：最新命令胜出，graph clear 清空它。

x = {1, 2, 3, 4, 5}
y = {2.1, 4.2, 5.8, 8.1, 9.9}

1.24 随机数

random() 抽取 [0, 1) 中的均匀随机数，random(a, b) 抽取 [a, b) 中的一个， randint(a, b) 抽取闭区间 [a, b] 中的一个整数：掷骰子：

randseed(7)
randint(1, 6)

3

序列是可复现的：randseed(n) 用 n 重新设定随机种子并显示它，因此相同的种子 在每个会话、每个前端都会重放相同的抽取结果。

randn(mu, sigma) 从均值为 mu、标准差为 sigma 的正态分布中抽值（Desmos 叫 randomNormal，TI 叫 randNorm）：

1.25 单位与换算

数字后跟单位就成为一个量：SI 单位的值加上它的量纲。单位表涵盖 SI 基本单位和导出单位（m、s、kg、A、K、mol、cd、Hz、N、 Pa、J、W、C、V、F、ohm、S、Wb、T、H、lm、lx、 Bq、Gy、Sv）、日常单位（min、hr、d、yr、L、t、bar、 atm、torr、psi、eV、mile、yd、ft、inch、nmi、lb、 oz、gal、qt、pt、mph、knot）以及第 1.29 节的天文后缀。 复合单位可以串联：60 mile/hr 和 5 m/s^2 都是单个单位。

60 mile/hr
60 mile/hr

SI 词头可以缩放任意单位：k M G T m µ n p 是千、兆、吉、太、毫、微、 纳、皮：5 km、3 MPa、1 GHz 都可以，2 kg 就是千克本身。

量纲会被检查：不同单位的量相加或比较会报错，而不是混在一起算：

5 m + 3 s
error: dimension error: cannot add 5 m and 3 s

算术会组合量纲：5 m * 3 m 是 15 m^2，(3 m)^2 是 9 m^2， sqrt(4 m^2) 是 2 m，量纲完全相消的整个表达式又回到普通数字 （5 m / 5 m 是 1）。量纲恰好匹配时，结果优先使用导出名称： 5 kg * 3 m / 1 s^2 得出 15 N。

换算。 expr in 单位（或 expr -> 单位）以指定单位显示一个量； 量纲必须匹配。in 的绑定最松，所以 5 m + 3 m in km 换算的是整个和：

20 m/s

2 m^2 in cm^2
20000 cm^2

第 1.15 节的基本字面量就是为此而生的：0b101、0o17、0xFF。位运算符 作用于整数，返回精确的整数：

15
运算符 含义
a & b 按位与
a | b 按位或
a xor b 按位异或
~a 按位取反（二进制补码）

a >> n 右移，算术移位（除以 2^n，向下取整）

1.27 隐式关系

含两个未知数的等式可以画成曲线：图形家族用移动方块采样该关系并绘制其零等高线。圆、抛物线和竖直线各一条命令：

1.28 矩阵

矩阵是数字的网格，写成列表的行：[[1, 2], [3, 4]] 是 2×2 矩阵。+ 和 - 逐元素运算（形状须相同），* 是矩阵乘法，数字逐元素缩放，^ 是整数 次矩阵幂（A ^ 0 是单位阵，所以幂需要方阵）。M[2][1] 是第 2 行第 1 列的元素：行像列表一样从 1 开始索引。

[[1, 2], [3, 4]] * [[5, 6], [7, 8]]
[[19, 22], [43, 50]]

矩阵函数覆盖课堂需求：det(M)（仅方阵）、inv(M)（奇异矩阵报错）、 transpose(M)、trace(M)（方阵）、dim(M)（{行, 列} 列表），以及 ref(M) 与 rref(M) 行化简。线性方程组通过增广矩阵的 rref 求解：

rref([[2, 1, 5], [1, -1, 1]])
[[1, 0, 2], [0, 1, 1]]

各行读出 x = 2、y = 1：即化简后增广矩阵的最后一列。精确分数像 列表一样显示在矩阵里，所以 inv([[1, 2], [3, 4]]) 显示 [[-2, 1], [3/2, -1/2]]。

1.30 金融

epher 说钱和说天文一样流利：货币时间价值求解器、贷款摊还、利息和 现金流分析，全部离线可用。本节的每个结果都是纯数字：不是货币 字符串：答案与币种无关，可以直接参与后续运算。利率一律指每期 利率，写成小数：0.08/12 是按月计息的 8% 年利率，0.01 是 1% （1.2 节的 % 后缀也能用：6 * 100% 就是 0.06）。

符号约定。 求解器遵循计算器行业的标准（TI 约定）：付出的钱为 负，收到的钱为正。对一笔你借入的贷款，放款为负、还款为正；对一 份储蓄计划，存款为负、到期取出的积蓄为正。五个字段只要自洽，余 额就为零：

pv*(1+i)^n + pmt*(1+i*begin)*((1+i)^n - 1)/i + fv = 0

符号弄反（贷款和还款同为负）意味着"钱永远无法平衡"，求解器会 报出域错误，而不是给出一个无意义的数。

货币时间价值求解器。 五个函数各自求出五个字段中的一个，其余 四个由你给出。n 是期数，i 是每期利率，pv 是现值，pmt 是 每期付款，fv 是期末值：

函数 求出
tvm_pmt(n, i, pv, fv) 每期付款
tvm_n(i, pv, pmt, fv) 期数
tvm_i(n, pv, pmt, fv) 每期利率
tvm_pv(n, i, pmt, fv) 现值
tvm_fv(n, i, pv, pmt) 期末值

经典的 8% 房贷：100,000 的贷款，每月还 733.76，共 360 期：

tvm_pmt(360, 0.08/12, -100000, 0)
733.764573879

一生支付的利息等于每期付款乘以期数再减去本金：

tvm_pmt(360, 0.08/12, -100000, 0) * 360 - 100000
164155.246597

tvm_i 从报价月供反推利率（略低于 8%/12，因为 733.76 是四舍五 入过的）：

tvm_i(360, -100000, 733.76, 0)
0.00666661199068

tvm_n 回答"要多久"。每月还 900 而不是最低还款额：

tvm_n(0.08/12, -100000, 900, 0)
203.163223431

约 203 个月，而不是 360 期。银行的报价也能自证：100,000 的贷款、 年利率 5%、月供 536.82，确实对应 30 年：

tvm_n(0.05/12, 100000, -536.82, 0)
360.002521488

（注意符号反了过来：这里贷款是收到的钱，所以为正，月供为负。）

tvm_fv 让储蓄计划生长：每月 200，存 40 年，年利率 6%：

tvm_fv(480, 0.06/12, 0, -200)
398298.146866

tvm_pv 给一串未来付款定价：要在 5% 的收益下连续 20 年每月支付 1,500，基金今天得有多少钱：

tvm_pv(240, 0.05/12, 1500, 0)
-227287.969611

答案是负的，因为今天买下这笔年金是流出的钱。反过来：为了达到 一个目标每月要存多少：把目标放到 fv 上问 tvm_pmt：5% 的收 益下，十年攒出 50,000 每月要存 322：

tvm_pmt(120, 0.05/12, 0, -50000)
321.994242862

五个函数都接受一个可选的末参数 begin：0 表示付款发生在每期期末 （默认），1 表示期初（先付年金：房租、大多数工资都是先付）。 期初付款多生一期利息，所以月供略低：

tvm_pmt(360, 0.08/12, -100000, 0, 1)
728.90520584

利率搜索上限为每期 100%，期数搜索上限为一千万期；超出范围（或符 号组合永远无法平衡）会报出域错误，并说明它尝试过的范围。

摊还。 amort(p, r, n, k) 是利率 r、共 n 期的贷款 p 在还了 k 期之后的剩余余额：k 为 0 时就是本金，k 为 n 时是零：

amort(100000, 0.08/12, 360, 120)
87724.7039064

8% 房贷还了十年后，还欠 87,725。一个循环（1.10）就能把它变成摊 还表，每五年一行：

for k in 0 to 360 step 60 do amort(100000, 0.08/12, 360, k)
{100000, 95069.8567174, 87724.7039064, 76781.5595143, 60477.9628062, 36188.1192209, 0}

利息。 simple_interest(p, r, t) 是 p*r*t， compound_interest(p, r, n) 是 p*(1+r)^n - p：两者给出的都是 挣到的利息，不是余额：

simple_interest(1000, 0.05, 2)
100

compound_interest(1000, 0.05, 2)
102.5

余额本身就是普通算术：这正是"纯数字"的意义：

1000 * 1.05 ^ 2
1102.5

两个日常利率，同样的构造。名义年利率 6% 按月复利时的实际年利率 （有效年利率），以及 72 法则算出的 6% 翻倍时间：

(1 + 0.06/12) ^ 12 - 1
0.0616778118645

72 / (6 * 100%)
12

npv(0.1, {-100, 60, 60})

结果以大号文字显示在输入框下方。第 1 章的所有内容在这里都适用，包括变量、函数和脚本。简短的单个答案留在这一行。较长的答案 - 包含多个答案的脚本输出、表格或长数字 - 显示在结果面板（即同时显示图形的面板）中，每个答案占一行；在手机上面板会自动滑入视野。 答案左侧有一个复制图标 - 按下它，答案的值就会进入剪贴板，每行一个；结果面板中的长答案也以同样方式复制。

输入名称时会自动出现建议列表：方向键移动高亮，Enter 或 Tab 接受，Esc 关闭，点击也可接受且无需离开键盘。每条建议都带有函数或常量的简短说明。F1 在键盘上方的提示条中显示光标处词语的同样说明。如果在一个空输入行中首先输入的是运算符（+ - * / ^ % !），epher 会自动插入 ans，让该行从上一个答案继续。

屏幕键盘替你输入，效果与按下按键完全相同。它的分组覆盖整个语言：123 数字与运算符、trig、ƒ 函数、nΣ 数字与统计、data 矩阵、列表和字符串（负责输入 [[1, 2], [3, 4]]、{1, 2, 3} 和 "text" 的分组）、0x 转换与进制、dist 回归与分布族、$ 财务、π∇ 常量与绘图命令，以及 ☉ 天文（唯一可滚动的分组）。本指南中的每个函数都在某个按键上。打开 key hints（? 按钮）可为每个按键加注说明，或停留在某个按键上阅读其作用。

设置菜单（齿轮图标，或在手机上 ☰ → 设置）包含三组。主题和语言名副其实。结果决定答案的显示方式：精确分数（默认开启，因此 1 / 3 显示为 1/3）、记数法（自动、科学或工程）和千位分隔符。这些只是显示设置；底层的值仍是普通数字。

2.3 历史记录

每次计算都会添加到结果下方的历史列表中，你可以回看自己做过什么。最新的条目显示在顶部，历史标题左侧的垃圾桶图标可以清空它（终端里是 Ctrl+L，或点击同一个图标）。历史记录在页面打开期间保留。

每个条目之间以细线分隔：单行表达式占一行，多行脚本则是一个显示其全部行的条目。点击某个条目即可将其加载回输入框并重新运行。

2.4 绘图

输入 graph 加一个表达式，然后按回车：

graph x ^ 2

epher 在带标签坐标轴的网格上，从 x = −10 到 x = 10 绘制曲线 y = f(x)，位于输入框下方。你可以绘制任何表达式，包括自己的函数：

def f(x) = x ^ 3
graph f(x)

每行 graph 都会在同一张图中添加一条曲线，每条曲线有自己的颜色。所有曲线都是实线，图例和曲线端点的标注才是不靠颜色区分它们的方式。graph clear 会清空图形，图形面板顶部的 Clear graph 按钮会同时清空曲线和 3D 曲面。TUI 在 Graph 菜单中保留了这条命令。

在图形面板顶部，Clear graph、Copy SVG 和 Save PNG 旁边，工具栏可以隐藏关注点列表和绘制在图形上的标记点。每个图形正上方都有一条由图标命名的滑块条，说明文字在各自的提示框里：线条粗细（2D 曲线用 0 到 4、步长 0.1 的滑块，3D 图形用 0 到 0.4、步长 0.05 的滑块，默认 0.2 - 只显示当前图形类型的滑块，每种类型各自记住自己的值）；每种图形还有缩放滑块，3D 和太阳系视图另有水平与垂直旋转速度。按下某个滑块的图标会把它重置为默认值。图例中的每一项前面都有一个复选框，默认勾选：取消勾选会把曲线、3D 曲面、空间曲线或太阳天体从图形、它的关注点和 SVG 导出中隐藏。

graph x ^ 2
graph x ^ 3

表达式没有值的点（例如除以零）会被跳过，在曲线中留下空隙。而实际上是垂直渐近线的跳跃永远不会画成连接线。

2.4.1 可以绘制什么

自选定义域：

graph sin(x) from 0 to 2*pi

参数曲线（t 从 0 到 2π）：

graph param 2*cos(t), 3*sin(t)

极坐标曲线：

graph polar 1 + cos(theta)

区域：y < 为曲线下方区域着色，y > 为上方着色：

graph y < x ^ 2

2.4.2 读懂图形

追踪： 将指针移到图形上，或将焦点放在图形上并按箭头键。曲线上最近的点会被标记，其坐标显示在图形下方。

关注点： 每次执行 graph 命令后，epher 会找出每条曲线的根和转折点以及曲线之间的交点，在图形上标记出来，并列在图形下方：

root (-1, 0)   minimum (0, 0)   root (1, 0)

表格： table 命令会打印数值表（表达式没有值的行留空）：

可选的 derivative <表达式> 子句添加第三列，即该表达式在每个 x 处的数值导数：

table x ^ 2 from -2 to 2 points 5 derivative x ^ 2
         x           y          y'
        -2           4          -4
        -1           1          -2
         0           0           0
         1           1           2
         2           4           4

表格单元格遵循结果设置：启用精确分数（默认）时，是简单分数的值 会以分数显示：table x / 3 from 0 to 1 points 4 列出 1/3 而不是 0.333。

table x ^ 2 from -2 to 2 points 5
         x           y
        -2           4
        -1           1
         0           0
         1           1
         2           4

还有两个子句覆盖剩下的工作。values <列表> 用数据列表充当 x 列，而不是等距网格：把数据交给它，看它变换：

d = {1, 2, 3, 4, 5}
table x ^ 2 values d
         x           y
         1           1
         2           4
         3           9
         4          16
         5          25

exact / approx 则为这一张表强制单元格的显示：exact 在凑得准时显示简单分数，approx 显示小数；各自只对这一条命令覆盖结果设置。

2.4.3 滑块与导出

定义一个常量并在图形中使用它，图形下方就会出现一个滑块。拖动它（或用箭头键移动它），每条曲线都会重绘：

const a = 1
graph a * x ^ 2

每种图形都以同样的方式缩放：在它上面滚动鼠标滚轮（或在触摸屏上捏合）即可放大缩小，图形上方的缩放滑块会随之移动。数据图（散点图、直方图和箱线图）与曲线图完全一样可以缩放。

复制 SVG 把当前图形复制为自包含的 SVG 图片，方便粘贴到文档中。颜色已内嵌，背景透明，因此可以放到任何页面、幻灯片或文档上。保存 PNG 把同一张图以两倍大小保存为位图，曲线保持清晰，背景同样透明；桌面版会询问保存位置，浏览器版保存到下载文件夹（或按浏览器的支持情况询问）。滑块行和动画常量位于图形正下方、关注点列表上方。动画滑块是真正的控件：抓住它的指示器拖到新值（抓取会先停止动画），或在它获得焦点时用方向键微调。

2.4.4 3D 曲面

graph3d 在正方形定义域（−5 到 5，或你的 from a to b）上绘制曲面 z = f(x, y)：

graph3d x ^ 2 - y ^ 2

离你更近的网格线画得更深，形状因此更有纵深感。多条 graph3d 行会像曲线一样叠加在同一张图中，graph3d clear 会清空图形。拖动可以旋转视图，或将焦点放在图形上并用箭头键旋转。终端界面把同一个曲面绘制成 ASCII 线框图，用箭头键旋转它。

空间曲线用 param 画：graph3d param cos(t), sin(t), t 在你给的 t 范围上（from 0 to 6.28318）画一条螺旋线，默认 0 到 2pi。同一个面板，同样的旋转、缩放和动画。

2.4.5 动画

每个滑块都有一个播放按钮。它让滑块对应的常量在滑块范围内逐步变化并循环：指示器走完整条轨道，到达终点后回到起点。这是计算器做动画的标准方式：你让一个参数动起来，所有用到它的东西都会跟着动。再次按下按钮就会暂停。

“时间”变量不过是你动画化的一个常量：

const t = 0
graph sin(x - t)

播放 t 的滑块会让波形移动。3D 曲面同样可以动画化。先定义一个常量，然后播放它的滑块：

const a = 1
graph3d sin(a * (x ^ 2 + y ^ 2)) from -3 to 3

在终端界面中，空格键开始和停止动画。

网页应用是一个渐进式网页应用：访问一次后即可完全离线使用，还可以像普通应用一样安装。

  • Chrome、Edge 或 Android： 点击地址栏中的安装图标（或浏览器菜单中的安装应用），然后确认。
  • iPhone / iPad（Safari）： 点击分享 → 添加到主屏幕。
  • 其他浏览器： 在菜单中查找安装或添加到主屏幕。

安装后，从主屏幕或应用列表启动它。即使没有网络连接也能瞬间打开。

2.6 网页应用不能做什么

网页应用把你的工作保留在当前会话中：它计算表达式、绘制图形（第 2.4 节）并保留历史记录。save、save script 和 language 命令在桌面、命令行和终端版本中可用（第 3、4、5 章）。在网页应用中，它们会回复一条说明：保存功能在那些版本中可用。最近的活动会被记住 - 历史、变量、函数和最后一个答案在关闭应用后依然保留，只保存在这个浏览器里。

3. 桌面应用

桌面应用是同一个网页应用外面的普通窗口。第 2 章的内容全部适用；区别只在于安装和启动方式。

3.1 安装

从 epher 网站为你的系统下载一个安装程序：

  • Windows： 运行 epher-windows-x86_64.exe。安装程序会把 epher 加入你的 PATH。打开一个新的 CMD 或 PowerShell 窗口，epher "2 + 2" 即可使用。由于构建未签名，首次启动请选择更多信息 → 仍要运行。
  • macOS： 打开 epher-macos-aarch64.dmg 并把 epher 拖入应用程序文件夹。由于构建未签名，首次启动需要右键 → 打开。
  • Linux（Debian/Ubuntu）： .deb 包
sudo apt install ./epher-linux-x86_64.deb
  • Linux（Fedora/RHEL）： .rpm 包
sudo dnf install ./epher-linux-x86_64.rpm

chmod +x epher-linux-x86_64.AppImage
./epher-linux-x86_64.AppImage

curl -fsSL https://epher.org/apt/KEY.gpg | sudo tee /etc/apt/keyrings/epher.gpg >/dev/null

sudo apt update && sudo apt install epher

curl -fsSL https://epher.org/epher.repo | sudo tee /etc/yum.repos.d/epher.repo >/dev/null

每个安装程序都包含完整的 epher：桌面应用、命令行（第 4 章）和终端界面（第 5 章），全部是同一个 epher 命令。在 Linux 上，软件包会把 epher 安装到 /usr/bin。

3.2 使用

像启动其他任何应用一样启动 epher。你会看到一个与网页应用界面相同的窗口：输入表达式，按回车或点击 =，然后阅读结果。绘图在这里同样有效。graph x ^ 2 会在窗口中绘制（第 2.4 节）。窗口可以自由调整大小。菜单栏包含 Help → In-app user guide，与本页相同的指南，其中的示例点击即可载入。

你也可以从终端打开它：不带参数的 epher（或 epher gui）会启动桌面应用。在 macOS 上，使用应用内的安装 epher 命令按钮，把 epher 放到终端 PATH 中。

3.3 存储：与 CLI 和 TUI 共用同一个存储

桌面应用与命令行和终端版本共用存储。函数、常量、脚本、历史记录和语言偏好存放在同一个地方，你电脑上的 ~/.epher（或 EPHER_STORE_DIR，见第 4.6 节），在一个版本中保存的所有内容都可以在其他版本中使用：

def area(w, h) = w * h
save area

在桌面应用中定义 area，用 save 保存，关闭窗口。然后打开 CLI，area(3, 4) 直接可用。反过来也一样：打开桌面窗口时，在 CLI 或 TUI 中保存的函数和脚本已经在那里了，包括保存的脚本设置的变量。第 4 章的 save、save script 和 language 命令在这里的用法完全相同。

你在 CLI、REPL、TUI 或桌面应用中输入的命令都会加入同一份历史记录，会话也会随之迁移：你赋值的变量和 ans 值会从一个版本跟随你到下一个版本。共享存储是实时的：当两个版本同时打开时，一个版本中的更改会立即反映到另一个版本中（桌面应用和 TUI 会监视存储并自动刷新）。

浏览器中的网页应用是唯一不使用这个存储的版本。每次会话相互独立（第 2.6 节）。

4. 命令行（CLI）

CLI 是与桌面应用同一个 epher 程序的文本一面。它有三种模式：单次计算、管道脚本，以及用于较长时间工作的交互式会话。

随时可以获得帮助：运行 epher --help（所有命令和示例），或 epher help（完整手册；在 Linux 安装包上就是 man epher 手册页）。

每个安装程序都自带整个脚本合集 ： 也就是网站 Scripts 页面浏览的那些脚本 ： 并把它们安装到程序旁边。网站上、脚本 README 中以及下文里可以复制的终 端命令都指向这个安装好的文件夹，所以只要装好 epher，它们就能直接运行：

# Debian, Ubuntu, Fedora (deb, rpm)
epher /usr/lib/epher/scripts/astronomy/moon/full-moons.epher

# Windows (PowerShell)
epher "$env:LOCALAPPDATA\epher\scripts\astronomy\moon\full-moons.epher"

# macOS
epher /Applications/epher.app/Contents/Resources/scripts/astronomy/moon/full-moons.epher

4.1 单次计算

把表达式作为参数传入：

epher "2 + 3 * 4"
14

第 1 章中任何单一表达式都可以：

epher "if 3 > 2 then 10 else 20"
10

以减号开头的表达式可以直接使用：

epher "-2 + 5"
3

单次模式用于脚本，从单个表达式一直到整个程序。每条语句的值各占一行打印：

epher "x = 10; x + 5"
10
15

在参数中用换行符连接的语句同样有效。第 1 章的所有内容都可用：变量、函数、循环，一切。而且各行共享同一个会话，就像管道脚本一样（第 4.2 节）。

4.2 管道脚本

epher - 从标准输入逐行读取表达式，就像脚本语言在管道中的用法：

# Linux and macOS (bash, zsh)
printf "x = 3\nx * 10\n" | epher -

# Windows PowerShell
"x = 3`nx * 10" | epher -
= 3
= 30

第 1 章的所有内容都可以用，而且各行共享同一个会话：前面定义过的函数后面可用，save 照常写入同一个存储。出错会打印出来，脚本继续运行。一行可以用 ; 连接多条语句。换行符和 ; 在 epher 中处处含义相同。

文件也是同样的用法：epher plots/sine.es 按顺序执行文件的每一行并打印每个结果。当参数命名一个已存在的文件且包含 .、/ 或 \ 时，它会被当作文件 - 所以 epher x 仍然对名字 x 求值。

4.4 保存函数、常量和脚本

定义一个函数，然后保存它：

epher> def fib(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2)
epher> save fib
saved fib

save fib 命令把函数存到磁盘。下次启动会话时，fib 已经定义好了：

epher> fib(10)
= 55

常量的保存方式相同。对常量名使用 save：

epher> const tax = 0.2
= 0.2
epher> save tax
saved tax

要保存整个脚本（你输入的最后一行），使用 save script：

epher> x = 0; while x < 5 do x = x + 1; x
= 5
epher> save script count_to_five
saved script count_to_five

保存的脚本会在 epher 启动时自动运行，所以它们定义的一切都为你准备好了。

你也可以随时用 load count_to_five 载入已保存的脚本，或把它留作普通文件并运行 load count_to_five.es；epher count_to_five.es 则直接在命令行运行它（第 4.2 节）。

4.5 更改界面语言

界面语言取自你设备上设置的语言。要覆盖它，输入 language 加下列之一：en、zh-CN、hi、es、fr、ar、de、pt：

epher> language fr
language set to fr

选择会被记住，供下次使用。注意：你输入的语言（表达式语言）始终相同，与界面语言无关。

4.6 数据存放在哪里

函数、脚本、历史记录和语言选择存放在你电脑上的一个文件夹中：

删除该文件夹即可完全重新开始。要使用其他位置，请在启动 epher 前设置环境变量 EPHER_STORE_DIR：

5. 终端界面（TUI）

TUI 是交互式会话的全屏版本，运行在终端内。它与桌面应用同属一个 epher 程序。用以下命令启动：

5.1 屏幕

屏幕分为几个面板：

  • History（历史）：你输入的每一行及其答案。
  • Graph（图表）：graph 命令绘制的图形（底部）。
  • 提示行显示键盘快捷键。

5.3 绘图

输入 graph 加一个表达式，然后按回车：

graph x ^ 2

epher 在 x = −10 到 x = 10 之间取样曲线，并以 ASCII 图形绘制在 Graph 面板中；图形上方的图例标注所绘内容。

graph clear 会清空图形，Graph 菜单也能做同样的事；Help 菜单会在 TUI 内打开本指南（方向键滚动，Esc 关闭）。Settings 菜单可以隐藏图形下方列出的关注点。

你可以绘制任何表达式，包括自己的函数。先定义一个，再绘制它：

def f(x) = x ^ 3
graph f(x)

每行 graph 都会为图形添加一条曲线，用各自的符号（o、x、+、*）绘制；graph clear 会清空图形。与网页应用相同的语法同样适用：定义域（graph sin(x) from 0 to 2*pi）、参数曲线（graph param 2*cos(t), 3*sin(t)）、极坐标曲线（graph polar 1 + cos(theta)）和区域（graph y < x ^ 2 为曲线下方区域着色）。

表达式没有值的点（例如除以零）会被直接跳过，在图中留下空隙。每次执行 graph 命令后，TUI 都会在图形下方列出关注点（根、转折点和交点）。table 命令（第 2.4.2 节）在这里同样有效。

graph3d x ^ 2 - y ^ 2 把 3D 曲面绘制成 ASCII 线框图。输入为空时用方向键旋转它，按空格键让滑块常量动起来（第 2.4.5 节）。底部的提示行只在显示 3D 曲面或可动画曲线时才显示方向键和空格提示。

graph save plot.svg 会把当前图形写为与网页应用复制 SVG按钮相同的 SVG 图片；graph3d save file.svg 会从你当前查看的角度保存 3D 线框。

5.4 保存与持久化

TUI 与 CLI 共享存储：在其中一个保存的内容在另一个中同样可用。函数、脚本、历史记录和语言偏好存放在 ~/.epher（第 4.6 节），save、save script 和 language 命令在这里同样有效。

6. 你的数据与隐私

  • 已安装的 epher 程序（桌面应用、CLI 和 TUI）把函数、脚本、历史记录和语言选择本地存放在 ~/.epher（或 EPHER_STORE_DIR）。不会离开你的电脑。
  • 网页应用 不往磁盘写任何东西：历史记录只在页面打开期间有效。网页应用可以离线运行，因为页面本身由你的浏览器存储。

五个版本都在你的设备上完成全部计算。不会向任何地方发送任何内容。
